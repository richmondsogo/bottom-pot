## Cross-Cutting Orchestrator Observations

1. **HTTP Client Creation ([`src/monitoring/board_monitor.py`](../../src/monitoring/board_monitor.py#L174), [`L211`](../../src/monitoring/board_monitor.py#L211))**: When `poll_due_boards` or `run_loop` instantiates its own HTTP client, it constructs a bare `httpx.AsyncClient(...)` rather than `create_ssrf_safe_async_client(...)` from [`src/safety/url_safety.py`](../../src/safety/url_safety.py#L227).
2. **Cancellation Handling ([`board_monitor.py`](../../src/monitoring/board_monitor.py#L187), [`board_adapters.py`](../../src/providers/board_adapters.py#L203))**: `poll_due_boards` uses `asyncio.gather(..., return_exceptions=True)` without re-raising `asyncio.CancelledError`, and `GreenhouseBoardAdapter.check_board` detail fan-out likewise discards exceptions from `gather(..., return_exceptions=True)`.
3. **Ad-Hoc Reconciliation Policy**: Thresholds (`1` vs `2`) are hardcoded inside each `BoardCheckResult` return site instead of a central policy object, and there is no cross-poll ID-drift detector (`source_url` stable while `job.id` changes).
4. **Wall-Clock Coupling**: Adapters call `time.time()` directly, and extraction falls back to `datetime.now(timezone.utc)`, preventing deterministic clock injection across poll outputs.
5. **Monolith Size**: [`src/providers/board_adapters.py`](../../src/providers/board_adapters.py) holds 4,313 lines mixing all 9 providers, shared detail retry logic, and shared pagination helpers in one file.
